# FlowBoard — Responsive Project Management Dashboard

A front-end concept project built with React, Vite, CSS, and Lucide icons.

## Project type
- Front-End only
- Mock / Concept project
- No backend
- No database
- No external personal data
- No image assets

## Features
- Responsive dashboard layout
- Sidebar navigation
- Search and task filtering
- Add-task modal
- Interactive task completion
- Dark / light mode
- Project progress cards
- Responsive mobile layout
- Accessible buttons and labels

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Portfolio note
This is a self-created training/concept project for portfolio presentation. The dashboard uses fictional UI content and sample metrics only.
